# 교회 PPT 메이커

찬양 제목만 입력하면 AI가 가사를 찾아 **Verse / Chorus / Bridge** 로 나누고,
PowerPoint의 **구역(섹션)** 까지 나눠서 예배용 PPT를 자동으로 만들어 주는 윈도우 프로그램입니다.

## 할 수 있는 것

| 기능 | 설명 |
|---|---|
| 🔍 제목으로 가사 찾기 | 제목(+아티스트)을 넣으면 AI가 인터넷에서 가사를 찾아 파트별로 나누고 순서(송폼)까지 정리 |
| ✂️ 붙여넣은 가사 나누기 | 가지고 있는 가사를 붙여넣으면 AI가 Verse/Chorus/Bridge 로 정리 (단어는 바꾸지 않음) |
| 🎼 악보 사진으로 만들기 | 악보 사진(여러 장)이나 PDF를 넣으면 가사·1절/2절·반복기호를 읽어서 정리 |
| ⚡ AI 없이 자동 나누기 | 반복되는 연을 후렴으로 추정. 반복이 없으면 **구분 없이 쭉 이어지는 가사**로 처리 |
| 💾 메모장(txt) 저장 | 가사는 파트가 구분된 메모장 파일로 자동 저장 → 오른쪽 **가사 보관함**에서 다시 사용 |
| 📖 성경 본문 | 구절(예: 요한복음 3:16-18)과 번역본을 고르면 AI가 본문을 가져옴, 절 번호 표시 |
| 🎤 설교 | 제목/설교자/본문 표지 + 요점 슬라이드. 원고를 붙여넣으면 AI가 요점으로 요약 |
| 📝 광고·텍스트, 🏠 표지 | 교회 소식, 사도신경, 주기도문 등 자유 텍스트와 예배 표지 |
| 🎨 템플릿 | 가지고 있는 **PPT 파일(소스)의 디자인 그대로** 사용하거나, 소스가 없으면 **[템플릿 편집]** 에서 배경·글꼴·위치를 직접 디자인 |
| 📑 PowerPoint 구역 | 완성된 PPT가 `곡 제목 - Verse 1`, `곡 제목 - Chorus`, `말씀 - 요한복음 3:16` … 구역으로 나뉨 |

## 설치

### 방법 1. 실행 파일 받기 (가장 쉬움)
1. GitHub 저장소의 **Actions** 탭 → `교회 PPT 메이커 - 윈도우 실행 파일 만들기` → 가장 최근 성공(✅) 실행을 클릭
2. 아래 **Artifacts** 의 `ChurchPPT-windows` 를 내려받아 압축을 풀고 `ChurchPPT.exe` 실행
   - 처음 실행할 때 Windows SmartScreen 경고가 나오면 **추가 정보 → 실행**

### 방법 2. 파이썬으로 실행
1. [Python 3.10 이상](https://www.python.org/downloads/) 설치 (설치 화면에서 **Add python.exe to PATH** 체크)
2. 이 폴더(`church-ppt-maker`)의 **`run.bat`** 더블클릭 — 처음 한 번만 구성 요소를 설치합니다.

### 방법 3. 직접 exe 만들기
`build_exe.bat` 더블클릭 → `dist\ChurchPPT.exe` 가 만들어집니다.

## AI 사용 준비 (Claude API 키)
1. <https://console.anthropic.com/settings/keys> 에서 API 키 발급 (결제 등록 필요, 사용한 만큼 과금)
2. 프로그램 위쪽 **⚙ 설정** → API 키 붙여넣기 → **연결 테스트**
3. 모델은 기본값(Claude Opus 5.5)을 추천합니다. 비용을 줄이려면 Sonnet 5.5 / Haiku 5.5 선택
4. **가사 찾기·성경 본문**은 웹 검색을 사용합니다. 오류가 나면 Claude Console 에서 웹 검색 사용이 켜져 있는지 확인하세요.

> AI 없이도 가사를 붙여넣고 `[Verse 1]` 처럼 직접 나누면 PPT를 만들 수 있습니다.

## 사용 순서
1. 왼쪽 아래 **[+ 찬양]** → 제목 입력 → **[🔍 AI로 가사 찾기]**
   (또는 가사 붙여넣고 **[AI로 파트 나누기]**, 또는 **[악보 사진으로 만들기]**)
2. 가사와 **순서(송폼)** 를 확인/수정 — 예: `V1 C V2 C B C C`
3. **[+ 성경] [+ 설교] [+ 광고/텍스트] [+ 표지]** 로 예배 순서 채우기 (끌어서 순서 변경)
4. 위쪽 **템플릿** 선택 → 아래 미리보기 확인
5. **[▶ PPT 만들기]** — 곡 하나만 필요하면 찬양 화면의 **[이 곡만 PPT 만들기]**

예배 순서는 **[예배 저장]** 으로 저장해 두었다가 다시 열 수 있고, 프로그램을 닫으면 마지막 작업이 자동으로 기억됩니다.

## 메모장 가사 파일 형식
```
제목: 곡 제목
아티스트: 아티스트 이름
순서: V1, C, V2, C, B, C

[Verse 1]
첫 번째 줄
두 번째 줄

세 번째 줄          ← 파트 안의 빈 줄 = 여기서 슬라이드 넘김

[Chorus]
후렴 가사

[Bridge]
브릿지 가사
```
- 파트 이름: `Verse 1`, `Chorus`, `Pre-Chorus`, `Bridge`, `Tag`, `Intro`, `Outro`, `Interlude` (`1절`, `후렴`, `브릿지` 도 인식)
- 순서 약어: `V1` `V2` `C` `PC` `B` `T` `I` `O` — 비워두면 적힌 순서대로 한 번씩
- `[대괄호]` 가 하나도 없으면 **구분 없이 쭉 이어지는 가사**로 만들어집니다.
- 한 슬라이드 최대 줄 수는 **템플릿 편집 → 슬라이드 구성** 에서 정합니다 (기본 2줄).
- 메모장에서 직접 만든 파일(ANSI/UTF-8)도 `가사` 폴더에 넣으면 보관함에 나타납니다.

## 템플릿

### 소스 PPT 사용 (가지고 있는 디자인 그대로)
**템플릿 편집 → "가지고 있는 PPT 파일(소스)의 디자인 그대로 사용"** 에서 .pptx 를 고르면
그 슬라이드(배경, 그림, 글꼴, 위치, 전환 효과)를 복제해서 글자만 바꿔 넣습니다.

소스 PPT의 글상자에 아래 표시를 써 두면 정확히 그 자리에 들어갑니다.

| 표시 | 들어가는 내용 |
|---|---|
| `{{가사}}` | 가사 (이 표시가 있는 슬라이드 = 가사용) |
| `{{제목}}` | 곡 제목 / 성경 구절 / 설교 제목 / 표지 제목 |
| `{{부제}}` | 표지 부제·날짜, 설교자 |
| `{{본문}}` | 성경·설교·광고 내용 (이 표시가 있는 슬라이드 = 내용용) |
| `{{섹션}}` | Verse 1, Chorus 같은 파트 이름 |

- 표시가 없으면 1번 슬라이드의 **가장 큰 글상자**에 가사를 넣습니다. 글상자가 없으면 새로 만듭니다.
- 어떤 슬라이드를 가사/표지/내용용으로 쓸지 번호로 직접 지정할 수도 있습니다.
- 처음이라면 **[견본 소스 PPT 만들기]** → PowerPoint에서 꾸미고 저장 → 그대로 사용하면 쉽습니다.

### 직접 디자인 (소스가 없을 때)
배경색/배경 사진(어둡게 조절), 글꼴·크기·색·굵게·외곽선·그림자, 정렬, 위치(방송용 **하단 자막** 포함),
여백, 줄 간격, 파트 이름/곡 제목 표시, 곡마다 제목 슬라이드·빈 슬라이드, 구역을 파트마다/곡마다 나눌지 등을 고르고
오른쪽 미리보기로 바로 확인합니다. 기본 템플릿 4종(검정 배경, 방송용 하단 자막, 밝은 배경, 네이비)이 들어 있습니다.

## 저장 폴더
`문서\교회PPT` (설정에서 변경 가능)
```
교회PPT\
  가사\          ← 메모장 가사 파일 (곡마다 1개)
  템플릿\        ← 템플릿 설정(.json), 견본 소스 PPT
  예배순서\      ← 저장한 예배 순서
  완성된PPT\     ← 만든 PPT
```

## 꼭 알아두세요
- **AI 결과는 틀릴 수 있습니다.** 가사·성경 본문은 PPT를 만들기 전에 꼭 한 번 확인하세요.
  AI가 가사를 찾지 못하거나 거절하면 가사를 붙여넣거나 악보 사진을 이용하세요.
- 찬양 가사·성경 번역본에는 저작권이 있습니다. 예배 중 가사 사용은 교회가 가진 이용 허락(예: CCLI 등)의 범위에서 사용하세요.
- API 키는 이 컴퓨터의 사용자 설정 폴더(`%APPDATA%\ChurchPPT\settings.json`)에만 저장됩니다.
- PPT가 PowerPoint에서 열려 있으면 같은 이름으로 저장할 수 없습니다. 닫고 다시 만드세요.

## 개발자용
```
church-ppt-maker/
  main.py                 실행 시작
  churchppt/
    lyrics_format.py      메모장 가사 형식, 파트 이름/순서 처리, 슬라이드 나누기
    service.py            예배 순서 항목 → 슬라이드 목록
    ppt_builder.py        .pptx 생성 (직접 디자인 / 소스 PPT 복제 / PowerPoint 구역)
    ai.py                 Claude API (가사 검색, 파트 나누기, 악보 읽기, 성경, 설교 요약)
    design.py settings.py 템플릿·설정
    ui/                   PySide6 화면
  tests/                  pytest
```

```
pip install -r requirements.txt pytest
python -m pytest -q
python main.py --selftest out.pptx   # 화면 없이 샘플 PPT 생성 점검
```
